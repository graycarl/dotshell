预置组件一览

下面每一块都是模板自带的样式，写正文时直接就能用，不需要额外 CSS。每块都挂了 anchor —— 可以随手点开批注，正好试试手感。

提示块 .callout

三种语气，用来强调「需要多看一眼」的那句话。

默认：中性提示，补充背景或前提。
成功 / 确认：这项校验已经通过，不需要再看。
警告：这里需要你本人拍板，我不能替你决定。

正文、列表与行内代码

  • 列表项也可以挂 anchor —— 点它就能单独批注这一条。
  • 行内代码 ask_page.py new plan，以及 加粗、斜体、删除线。
  • 有序列表用来写步骤：
    1. 写正文
    2. 生成页面
    3. 复制结果

引用与分割线

批注导出的格式刻意保持简单：哨兵 + 标题 + 正文。人和模型读的是同一份东西。

选择题 data-pi-option

一个问题一组选项，单选；加 data-pi-multiple="true" 变多选。点已选中的项可以取消，答案会进导出结果的「选择」小节。

Markdown 块（不想手写 HTML 时）

页面自带的三件交互

① 点段落写批注正文里带下划线的块都能点；框选一段文字再点，会带上原文引用。
② 复制结果 + 预览右下角按钮把全文写进剪贴板，并在按钮上方弹出预览；被浏览器拦住时自动全选。
③ ↻ 载入最新内容agent 改完正文后点它，草稿原地保留。
批注存在本机浏览器里（key 是 ask-page:<id>），关掉页面也不会丢；想清空就点左下角「清空草稿」。
