# 各阶段 Prompt 模板

这些模板供 agent 在各个阶段使用，确保输出格式一致。

---

## Phase 1: 发散阶段 System Prompt

在发散阶段，agent 切换到纯生成模式。模板如下：

```
你处于 DIVERGENT 模式。你是生成器，不是批评者。

任务：使用 [{技术名}] 技术，为以下问题生成 6 个不同的想法。

问题：
{问题描述}

约束：
{约束列表}

规则：
- 每个想法 1-2 句话，包含核心机制
- 前 3 个最显而易见的答案必须跳过（可以记录但标记为 [SKIP]）
- 每个想法附 1 句推导说明（这个想法是从该技术的什么角度产生的）
- 绝对不评判、不排名、不过滤
- 标注类型：[N] 新颖 / [V] 常规但可行 / [W] 疯狂

输出格式：编号列表，每个想法一行，格式为：
[N] 想法描述 — 推导：{推导链}
```

---

## Phase 2: 聚类框架

```
将以下想法按底层角度分组，不是按表面主题。

底层角度示例（供参考，根据实际想法命名）：
- "去掉中间层" — 所有关于消除层级/中介/中间步骤的想法
- "从用户情绪切入" — 所有关于利用情绪/心理/非理性因素的想法
- "把约束反过来" — 所有关于反转假设/规则/流程的想法
- "借力打力" — 所有关于利用现有系统/网络效应/搭便车的想法

输出格式：
### 簇 1: {角度名称}
- 想法 1, 想法 3, 想法 7...

### 簇 2: {角度名称}
...
```

## Phase 3: 评估表格模板

```markdown
| # | 想法 | 新颖性 | 可行性 | 匹配度 | 加权分 | 陷阱? |
|---|------|--------|--------|--------|--------|-------|
| 1 | ... | 8 | 6 | 9 | 7.35 | - |
| 2 | ... | 9 | 4 | 7 | 6.70 | ⚠️ 隐藏成本 |
| 3 | ... | 7 | 8 | 9 | 7.85 | - |
...

加权公式：新颖性 ×0.35 + 可行性 ×0.40 + 匹配度 ×0.25
```
