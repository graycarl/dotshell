# 创意技术目录

以下 6 种技术均经过认知科学和创意研究验证。每次发散至少选用 2 种，优先选择角度差异大的组合。

---

## 1. 类比迁移 (Analogical Transfer)

**来源**：Synectics (Gordon, 1961)；Koestler 的"异类联想"(bisociation)

**操作**：从一个完全不相关的领域中借用一个机制、模式或结构，应用到当前问题上。

**步骤**：
1. 识别当前问题的核心结构（不是表面特征）
2. 选一个远距离领域（生物学、经济学、游戏设计、烹饪...）
3. 找出该领域中解决类似结构的方法
4. 映射回原问题，生成至少 5 个具体想法

**示例 prompt**：
> 如果 [问题域] 是一道菜、一场游戏、一个生态系统、一个金融市场...它会怎样运作？从中能借到什么机制？

---

## 2. 约束翻转 (Constraint Flip)

**来源**：Boden 的约束操纵框架；逆向头脑风暴变体

**操作**：系统性地移除、添加、或反转当前问题的一个核心约束，观察会产生什么。

**步骤**：
1. 列出当前问题 3-5 个"不可动摇"的约束
2. 依次移除/反转每一个约束
3. 在每个翻转后的空间中生成想法
4. 即使翻转后的想法不现实，也记录——它们常能催生变体

**翻转类型**：
- 移除：如果 [约束] 不存在，会怎样？
- 反转：如果 [约束] 反过来，会怎样？
- 极端化：如果把 [约束] 放大 10x 或缩小为 1/10，会怎样？

---

## 3. SCAMPER

**来源**：Bob Eberle (1971)，基于 Alex Osborn 的创意清单

**操作**：对现有方案按 7 个维度逐一变形，生成新想法。

| 维度 | 问题 | 应用于... |
|------|------|-----------|
| Substitute | 能替换什么？ | 材料、流程、人、地点 |
| Combine | 能和什么组合？ | 功能、用途、理念 |
| Adapt | 能借鉴什么？ | 其他产品、历史方案、自然界 |
| Modify | 能改变什么？ | 大小、形状、属性、意义 |
| Put to another use | 还能怎么用？ | 换个场景、换个用户群 |
| Eliminate | 能去掉什么？ | 简化、精简、做减法 |
| Reverse | 能颠倒什么？ | 顺序、角色、假设 |

## 4. 极端用户 (Extreme User Design)

**来源**：d.school / IDEO 设计思维工具箱

**操作**：为一个与目标用户完全不同的极端用户设计，然后反向提炼通用洞察。

**步骤**：
1. 定义当前的目标用户
2. 设计一个极端用户画像（完全新手 / 超级专家 / 儿童 / 80 岁老人 / 完全不同的文化背景）
3. 为该极端用户生成至少 5 个想法
4. 从每个想法中提炼可迁移回原用户的洞察

---

## 5. 逆向头脑风暴 (Reverse Brainstorming)

**来源**：经典创意技法，d.school/IDEO 标准化

**操作**：先故意想"怎么让问题更糟"，然后翻转过来。

**步骤**：
1. 提问："怎么才能让当前问题/系统/体验变得彻底失败？"
2. 生成 ≥8 个"破坏方案"
3. 将每个破坏方案翻转为正面解决方案
4. 翻转后的方案往往能揭示被忽视的设计盲点

**关键**：破坏方案的质量决定翻转后的价值。认真想"怎么搞砸"，不要敷衍。

---

## 6. 缩放 (Scale Shift)

**来源**：约束创造力研究，约束操纵的子类型

**操作**：将关键参数进行数量级缩放，观察出现的质变。

**步骤**：
1. 识别 2-3 个关键参数（用户数、时间、成本、频率、数据量...）
2. 分别进行 10x 放大 和 1/10 缩小
3. 在每个缩放下生成至少 3 个想法
4. 特别注意那些在某个缩放点会"破裂"但换个缩放点就成立的方案

**缩放示例**：
- 如果预算为 0，怎么做？
- 如果用户量 100x，什么会被压垮？有什么新机会？
- 如果必须在 24 小时内完成，怎么做？
