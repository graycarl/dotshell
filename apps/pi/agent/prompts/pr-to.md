目标分支：`${1:-main}`

请按以下步骤完成「提交 → 建 PR → 合并 → 切回目标分支」的全流程。执行 `gh` 命令前先阅读 github skill。

## 1. 摸清当前状态

- 工作区是否干净、是否已有领先目标分支的提交（两者都没有 → 无内容可提交，直接结束并说明）。
- 当前分支名是否如实反映这批改动的内容。

## 2. 落到正确的分支上

- 工作区干净、无待提交内容：忽略，不要做任何提交或分支操作，结束并汇报。
- 当前分支名与改动内容匹配：直接在当前分支提交。
- 当前分支名不匹配（包括正处在目标分支上）：先按改动内容创建合适分支，比如 feat/xx-xx, fix/xxx, chore/xxx 等，再提交。

## 3. 创建 PR 并合并

使用 gh 创建 PR 到目标分支，并且合并它，确保完成后切回目标分支。
